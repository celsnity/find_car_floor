# 주차층 (ParkFloor)

집 아파트 주차장에서 CarPlay 연결이 끊기는 순간, 내 차가 몇 층에 있는지 자동으로 기록해서 앱과 위젯에 보여주는 iPhone 앱.

> 상태: 소스와 Xcode 프로젝트는 Linux 환경에서 작성했고 **아직 한 번도 컴파일하지 않았습니다.**
> 구문 검사만 통과한 상태라 첫 빌드에서 타입·API 오류가 나올 수 있습니다.

## 빌드

1. `ParkFloor.xcodeproj` 를 Xcode 16 이상에서 엽니다. (iOS 17.0 이상 대상)
2. `ParkFloor`, `ParkFloorWidget` 두 타깃의 **Signing & Capabilities** 에서 Team 을 선택합니다.
3. 번들 ID(`com.celsnity.parkfloor`)나 App Group(`group.com.celsnity.parkfloor`)을 바꾸려면 아래 세 곳을 함께 바꿉니다.
   - 두 타깃의 Bundle Identifier
   - `App/ParkFloor.entitlements`, `Widget/ParkFloorWidget.entitlements`
   - `Shared/ParkingStore.swift` 의 `appGroup`
4. 실제 iPhone 에 설치합니다. 기압계와 CarPlay 는 시뮬레이터에서 동작하지 않습니다.
5. 층 추정 로직 테스트는 시뮬레이터에서 ⌘U 로 실행합니다.

파일을 추가·삭제했을 때 프로젝트를 다시 만들려면: `gem install xcodeproj && ruby tools/generate_project.rb`

## 처음 설정

1. 앱 → 설정(톱니바퀴) → 지도에서 집 주차장 위치를 지정합니다.
2. 홈 화면의 "자동 기록 준비" 카드에서 위치 **항상 허용**, **동작 및 피트니스**, 알림을 허용합니다.
3. 설정 → 주차장 구조에서 지하 층수를 맞춥니다. 깊이 값은 기본값 그대로 두어도 됩니다.
4. (선택) 단축어 앱 → 자동화 → CarPlay → "연결 해제될 때" → "즉시 실행" 에 **주차 층 기록** 동작을 추가합니다.
5. 홈 화면이나 잠금 화면에 "주차 층" 위젯을 추가합니다.

## 동작 방식

지하에서는 GPS 가 안 잡히므로 기압계를 씁니다.

1. 평소에는 아무것도 실행하지 않습니다. iOS 지오펜스가 집 반경 진입을 알려줄 때만 앱이 깨어납니다.
2. 그때 CarPlay 가 연결돼 있으면 기압계 상대 고도를 약 1초 간격으로 기록합니다.
3. CarPlay 연결이 3초 이상 끊기면 `깊이 = 최근 5분 중 가장 높았던 지점 − 주차 직전 고도` 를 계산합니다.
4. 층별 예상 깊이와 가장 가까운 층을 골라 저장하고, 위젯을 갱신하고, 알림을 보낸 뒤 완전히 멈춥니다.

층을 확인하거나 고쳐 주면 그 깊이를 해당 층의 실측값으로 학습해서, 다음부터는 설정의 기본 깊이보다 우선 적용합니다.

### 배터리

- 측정은 집 근처 진입부터 주차까지 몇 분 동안만 돌고, 20분이 지나거나 집 반경을 벗어나면 스스로 끝납니다.
- 측정 중 위치 업데이트는 백그라운드 실행을 유지하는 용도라 정확도를 최저(3km)로 둡니다. GPS 칩을 켜지 않습니다.
- 위젯은 기록이 바뀔 때와 자정에 한 번만 갱신합니다.

## 실차에서 확인이 필요한 부분

아래는 기기에서만 확인할 수 있어서 검증하지 못했습니다. 문제가 생기면 설정 → 진단 → 동작 기록에 단계별 로그가 남습니다.

- **CarPlay 감지**: 오디오 세션을 활성화하지 않은 상태에서도 출력 경로에 `.carAudio` 가 보이는지. 설정 → 진단의 "CarPlay" 항목이 차에서 "연결됨" 으로 바뀌는지 먼저 확인하세요.
- **지오펜스 시점**: 진입 알림이 늦어서 이미 지하에 들어간 뒤 측정이 시작되면 깊이가 실제보다 얕게 나옵니다. 그럴 때는 감지 반경을 키우세요.
- **저정밀 위치로 백그라운드 유지**: 측정 도중 앱이 중단되면 로그에 "측정 시작" 만 있고 결과가 없습니다.
- **깊이 기본값**: 지면→B1 4.5m, 층간 3.3m 는 추정치입니다. 처음 며칠은 층을 확인해 주는 것이 좋습니다.

### 알려진 한계

- 지하에서 자리를 찾느라 5분 넘게 돌면 지면 기준점을 놓쳐 얕게 나옵니다.
- 지상 위로 올라가는 주차 건물은 지원하지 않습니다 (지상과 지하만).
- 집 반경 안에서만 짧게 움직인 경우에는 측정이 시작되지 않습니다. 이때는 앱에서 직접 기록하세요.
- 무료 Apple ID 로 서명하면 7일마다 다시 설치해야 합니다.

## 구조

```
App/        앱 본체 (자동 감지, 화면, Siri·단축어 동작)
Shared/     앱과 위젯이 함께 쓰는 코드 (모델, 층 추정, 저장소, 색·표기)
Widget/     홈 화면·잠금 화면 위젯
Tests/      층 추정 로직 단위 테스트
tools/      Xcode 프로젝트 생성 스크립트
```
